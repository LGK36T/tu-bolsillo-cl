# data/

Estructura de almacenamiento de datos:

- `raw/`: Datos en formato original obtenidos de fuentes públicas oficiales.
  - `division_politico_electoral.csv`: División territorial y electoral de Chile (BCN).
- `processed/`: Datos depurados y normalizados listos para su uso.

## Consideraciones de privacidad (Ley N° 19.628)

No se almacena información sensible personal (RUT, domicilios particulares, teléfonos privados o antecedentes médicos).
